# Image Compressor

Compress JPG/PNG photos to WebP on your Android device — no cloud, no subscription, no internet needed.

A 10 GB camera roll can shrink to ~1 GB with virtually no visible quality loss.

## Features

- **Gallery viewer** — browse any folder, navigate subfolders, dark mode
- **Full-screen viewer** — pinch-to-zoom, double-tap zoom, swipe between photos
- **Share** — send photos directly to WhatsApp, Telegram, etc.
- **Delete & rotate** — manage photos from the viewer
- **Compression** — JPG/PNG → WebP, configurable quality & max resolution
- **Safe** — originals deleted only after successful compression
- **Background service** — runs with notification, survives app switching

## How to use

1. Set a **gallery root folder** to browse your photos
2. In **Settings**, select a **source** folder (e.g. `DCIM/Camera`) and a **final** folder
3. Adjust quality (default 65) and max resolution (default 1280px) if needed
4. Tap **Start** — compression runs in the background

## Install

Download the latest APK from [Releases](https://github.com/adegard/ImageCompressor/releases). Grant folder access when prompted — the app uses Android's SAF and only accesses folders you choose.
